디자인 시스템

게임 소스 코드에서 색상, 글꼴, 9-patch 프레임, 아이콘, 컴포넌트, 모션 값을 그대로 뽑았습니다. 이 페이지의 프레임과 아이콘은 모두 원본 PNG를 잘라 그린 것이고, 값마다 원본 코드 줄로 가는 링크가 달려 있습니다.

배율 defaultZoom 직업별 빌드 · 장비 티어 →

SPD 화면은 모두 게임 픽셀 단위로 짜여 있습니다. 실제 화면에는 PixelScene.defaultZoom배로 확대해서 그리고, 좌표는 align()으로 정수 화면 픽셀에 맞춥니다. 이 페이지도 같은 방식이라 위의 배율을 바꾸면 전체가 함께 커지고 작아집니다.

UI 색은 이름 붙은 상수로 정의되어 있고, 텍스트와 이미지에는 hardlight(color)로 입힙니다. 견본을 누르면 hex 값이 복사됩니다.

라틴 문자는 pixel_font.ttf로 그립니다. 한글·한자·가나는 getGeneratorForString이 별도 폰트로 넘깁니다(데스크톱은 Droid Sans, 안드로이드는 Noto Sans CJK, 그다음 NanumGothic, 그다음 NotoSansKR 순). 이 페이지도 "SPD Pixel", "Noto Sans KR" 순서로 지정해서 같은 방식으로 섞어 씁니다.

크기 단계 코드 집계

강조 마크업

RenderedTextBlock은 _나 **를 만날 때마다 강조를 켜고 끕니다. 강조색은 Window.TITLE_COLOR입니다.

게임 로그 채널

GLog는 메시지 앞의 접두어로 색을 정하고, GameLog가 접두어를 떼고 CharSprite 색을 입힙니다.

창, 버튼, 토스트, 탭은 모두 chrome.png (128×64) 한 장에서 잘라 쓰는 9-patch입니다. 가장자리(margin)는 그대로 두고 가운데만 늘립니다. 아래 슬라이더로 늘린 크기를 바꿔 볼 수 있습니다.

Icons.java의 enum 하나가 icons.png (256×128)의 사각형 하나에 대응합니다. 크기는 아이콘마다 다릅니다. 마우스를 올리면 툴팁 컴포넌트가 실제 코드와 같은 지연(0.5초)으로 나타납니다.

버프 아이콘

BuffIndicator의 번호가 격자 칸을 가리킵니다. 작은 시트는 7px 칸, 큰 시트는 16px 칸이고, 위치는 x = (i % cols) × cell, y = ⌊i / cols⌋ × cell입니다. 일부 아이콘은 게임 안에서 tintIcon()으로 색이 바뀝니다.

위의 토큰을 조합한 UI 부품입니다. 크기, 상태 변화, 쓰는 9-patch를 모두 코드에서 가져왔습니다.

간격과 크기는 창마다 상수로 따로 선언되어 있어서, 공통 규칙은 선언 빈도로 읽어야 합니다. 아래 표는 windows/, ui/, scenes/의 선언을 정규식으로 센 값입니다.

시간 값은 모두 코드 상수입니다. 버튼을 누르면 같은 값으로 재생됩니다.

tools/extract.py가 SPD 소스를 읽어 tokens.json을 만듭니다. 아래 CSS 변수는 그 JSON으로 만든 것입니다.
